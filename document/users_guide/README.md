# CityGML 3.0 Users Guide

An HTML version of the Users Guide can be found at [this location](https://cmheazel.github.io/CityGML3-Workspace/users_guide/20-066.html). This version will be updated every Friday evening.

A PDF version can be found [here](https://github.com/cmheazel/CityGML3-Workspace/blob/user-guide/20-066.pdf). This version is also updated every Friday evening.

## Content

This folder contains the text for the CityGML 3.0 Users Guide

* CityGML_Conceptual_Model_Users_Guide.adoc - the main document with references to all sections
* remaining adocs - each section of the Users Guide document is in a separate document: follow directions in each document to populate
* figures - figures go here
* images - Image files for graphics go here. Image files for figures go in the "figures" directory. Only place in here images not used in figures (e.g., as parts of tables, as logos, etc.)
* UML - UML diagrams, if applicable

## Building

To produce the HTML of the Best Practice run `HTML_Gen.bat`

To produce the PDF of the Best Practice run `PDF_Gen.bat`
